# Invest Learn Android App

This is an initial Android app skeleton for "Invest Learn" — an educational app to teach students entrepreneurship and leadership skills using interactive models and simple exercises.

How to open and run
- Open this project in Android Studio.
- Let Android Studio sync Gradle and download dependencies.
- Run the `app` module on an emulator or device (minSdk 21).

What’s included
- Basic app structure (Kotlin)
- Main screen with modules: Entrepreneurship, Leadership, Interactive Model
- Module activity with a sample interactive quiz

Next steps
